# 架构讨论纪要(design log,2026-08-01)

> 这是立项讨论中达成的**架构结论与开放决策**的固化,区别于 01–15 的研究/全景文件。后续讨论以此为准;若推翻某条,在此标注。研究深度见对应文件号。

## 核心结论

### 1. 端到端环 = 多时间尺度,非紧传感-运动环
五个频率分层,认知与渲染解耦:
- 渲染 90Hz(Mac/VP,RealityKit,纯动画平滑,不经大脑)
- 感知 ingest ~30Hz(VP→Mac,原始帧/mesh/手眼脸/截屏)
- 感知处理 5–10Hz(工作站,SAM3.1/VLM/屏幕VLM/情感融合 → 更新场景图 + 态势快照)
- **认知决策 1–5Hz**(工作站,大脑 → 动作 token + 语音)
- 事件中断 <200ms(本地,barge-in/注视变化/屏幕突发,不经大脑)
- 节奏(200–500ms 刻意反应)读起来**自然**,非迟钝。

### 2. 三层架构(subsumption 式,仿生)
- **慢审议层(大脑,1–5Hz)**:意图/计划+记忆+人格 → 动作 token、语音。决定"做什么、说什么"。
- **持续行为基线(行为状态机,Mac,常驻)**:idle 呼吸/眨眼/微动/周期瞥视/情绪微表情。大脑不发指令时撑"活着"。
- **快反射层(本地,<200ms,不经大脑)**:注视跟随(纯 IK)、barge-in(VAD)、侵入姿态调整。决定"瞬时反应"。
三层共用感知总线;反应速度递减、思考量递增。大脑只在"需要决定"时介入。

### 3. 决策解剖:基于内部状态+记忆+意图,非刺激→反应
决策 = `f(感知, 记忆, 角色内部状态, 活跃意图)`,不是 `f(感知)`。这让角色能在用户没说话时**主动**起身、在用户皱眉时**联想**——"像有内心"。内部状态(心情/能量/关系/当前姿态)跨 tick 持久。

### 4. 大脑 = LLM,VLM = 眼(关键纠偏)
- VLM 擅长"像素→文本/结构",不擅长长程推理/人格一致/稳定吐结构化动作 token。
- **推荐分工**:LLM-core(Qwen3/DeepSeek/GLM)推理决策+人格;VLM(Qwen3-VL/UniVR-34B)当"看一眼"的工具/感知;记忆=Zep/Graphiti。
- LLM 吐 JSON/动作 token 比稳;VLM 把世界翻译成文本喂 LLM。两者各跑各,96GB 工作站同驻余量足。
- **例外**:若第一优先是"说话像真人/极低延迟/原生 backchannel",大脑换 Omni/S2S(Qwen3-Omni / GLM-4-Voice)。
- 永不让 LLM 逐帧控制关节(类别错误);逐关节层若要用,是**专门策略网络(PHC/ExBody2 等),非大模型**。

### 5. 动画:三种操作逻辑,均"意图驱动"
- **极 A 命令→动画引擎**(库+状态机+IK+motion matching):像打游戏,漂亮/可控/快/稳,但**有界**(游戏感)。**当下效果不错的范例存在**:NVIDIA ACE、MetaHuman+Inworld+Audio2Face、Reallusion iClone、Apple Spatial Personas、VTuber rig。质量天花板=脸真好、身体略游戏感。
- **极 B 命令→物理控制器**(学好的策略逐关节):像控机器人,物理合理/抗扰动,但抖、为"任务"训不为"表演"训、集成重。
- **极 C 命令→生成式动作**(MotionLCM 等):AI 即兴演员,自由/新颖,质量/贴家具/风格一致性未成熟。
- **关键**:LLM 永远坐意图层;分叉是意图下面用什么兑现。
- **分通道混搭**(motion resolver 抽象,可升级旋钮):脸=Audio2Face-3D(开源,实时吐 ARKit52,已移植 Apple Silicon);注视=IK;手势=生成式;走动/idle/过渡=生成式或库;**贴家具的坐/躺/趴=库+affordance 拟合**(唯一被库束缚、且观众读不出"是不是演的"的部分)。
- 极 A 天花板对"陪伴感"多半够用(陪伴感主要靠脸+注视+对话时机);若要"不可预测的鲜活"才押极 C。

### 6. Vision Pro 数据预算(四档)
- **免费**:SceneReconstruction mesh(几何无标签)、PlaneDetection、WorldTracking+WorldAnchor(同设备跨会话持久)、HandTracking、EyeTracking(用户看哪)、RoomTracking、ObjectTracking(训练物)、ImageTracking、环境光、SharedCoordinateSpace(多 headset 共处)。
- **企业授权解锁**(你在申请):CameraFrameProvider(864×704 立体 L/R ~60fps,**只像素+内外参,无深度/分割**)、CameraRegionProvider、passthrough 合成画面。
- **自己算**:深度(立体视差)、语义(Vision 框架/VLM)、mesh 语义(2D lift 到 3D)、开放词表识别。
- **拿不到**:无授权→无原始帧;无现成深度流;mesh 无语义;无 ARWorldMap/跨设备异步共享;无用户全身骨骼;头显外部摄像头看不见用户自己的脸。

### 7. 企业摄像头 ≠ 3D 重建
- 几何(mesh)**免费就有**;摄像头给的是**像素→外观+语义**。
- 两种"3D 场景":**(A) 显示**=passthrough 真房间+虚拟角色(**不需重建**,你已看到真房间);**(B) 角色内部模型**=场景图(给大脑推理,非显示)。
- 企业摄像头服务于 (B)(让内部模型带语义),不服务于 (A)。
- 实时照片级 GS 重建是前沿非成品;且本项目**不需要照片级重建**(显示靠 passthrough)。

### 8. 角色"视觉" = 3D 场景图,非 POV 像素
- 原始数据是**用户第一人称**(头显朝前);对她而言画面含她自己。
- **推荐**:视角无关的 3D 场景图(结构化文本)直接喂 LLM 大脑;仅在需"凑近看"时从她位置渲染 POV(读屏/细看物体)。
- 限制:外部摄像头看不见用户脸 → 用户情绪靠**语音+注视+手势**,不靠脸。

### 9. 持久动态场景图 = 物体恒常性(核心需求,用户确立)
- **动态不预写**:每帧实时搭(摄像头帧+mesh→SAM3.1+VLM→融合);无任何预扫描地图。
- **世界 = 你走过之处的累积**:走过的区域移出视野仍留图;路过即刷新。你从没去过的地方她不知道(真实,非抓瞎)。
- **记忆 = 缓存的感知**(非依赖):换任何新房间都能从零实时搭;永远在"看",不依赖预地图。新房间=第一次见,不瞎。
- **关键设计原则:记忆=信念/规划;实时感知=交互时核验**。记忆会过期(你挪了躺椅),所以执行动作前用当前 FOV 局部重核验;不一致则优雅失败/重感。这是"物体恒常性"的工程实现,也是 [13] 最难子问题(记忆-现实对齐)的当下最稳解。
- 场景图节点:`{WorldAnchor UUID, 位置, CLIP 特征, 类别, affordance 标签, 时间戳, 置信度, 帧快照}` + 关系边(在…上/后/内/可达)。
- 持久层:几何基底(WorldAnchor,visionOS 管同设备重定位)+ 物体/实例层(HOV-SG 式,工作站)+ 时序/情景(Graphiti/Zep)+ 检索(Milvus/Qdrant+BGE-M3)。

### 11. 活感优先 / 算力不限(用户确立,2026-08)
**目标**:让角色"最活";算力不再是约束(96GB 工作站 + M1 Max 随便花)。

**关键判断(反直觉)**:活 = **连续 + 细微 + 时机准 + 连贯**,不是"反应最大"。全拧到 11 = 抽搐/恐怖谷。算力买的是**丰富与细腻**,不是**强度**。

**杠杆(把算力花在这些地方)**:
- **感知跑热、跑连续**(反转"事件驱动/按需感知"):SAM3+VLM+用户态连续高率跑,她始终知完整当前态。
- **连续微反应层**(活感主战场):韵律/情绪→脸、你移动→她身体朝向/重心、你注视→她注意跟随、对话节奏→呼吸/眨眼同步。本地、连续、永不关。
- **永不静止**:生成式 idle(呼吸/换重心/fidget/环顾,不重复)+ 连续共话语手势。别让她冻住一秒。
- **一直思考的大脑**:连续 inner-monologue/意图流 → 持续微动作涓流(始终 mentally present,不是等你说话才开机)。
- **连续前瞻(ForesightService 一直跑)**:预判你下一步 → 提前反应(话没完她已转头、你还没起身她已看向门)。预判是"活"的最高级形态。
- **连续 backchannel**:你说话时持续点头/挑眉/"嗯啊"/微表情。
- **物理一直跑**:接地、接触正确,不漂浮。

**算力解决不了的两件事(诚实)**:
- **反射仍须本地 <200ms**:barge-in/注视是**延迟 bound,不是算力 bound**;留本地,但可更丰富(注视还追情绪/手势指向)。
- **连续生成会抖/漂/穿模 → 须"行为导演"层**:做连贯/克制/时机——决定此刻哪个微反应该显、该压、怎么混。**算力让她"能"活,导演层让她"真"活。**

**哪些模型常驻跑热(96GB 同驻)**:Audio2Face(脸)、手势生成、生成式 idle、用户态连续估计、ForesightService——24/7 跑热。**70B 深推理仍按需**(它决定"聪不聪明/深不深",不决定"当下活不活";当下活感由上面那些连续层扛)。

**据此修订**:此 posture **反转**之前"省算力"取向的优化(事件驱动感知/认知、为省脑而下放便宜层、为省显存而模型瘦身)——在"活优先"下让位,改为**全链路跑热跑连续**。**仍保留(它们与活感不冲突)**:两层认知(70B 本就跑不到 30Hz,是延迟/合适度而非省算力)、反射本地(延迟)、场景图→上下文相关性编译(质量)、可观测(质量)、人设结构化(质量)、鲁棒降级(质量)。

### 12. 动作小脑定为"连续动作 VLA"+ 大脑/小脑双系统(2026-08,用户决定;修订 open-vla 首选)
**大脑/小脑双系统(GR2/GR00T 范式,升级结论4)**:
- **大脑 = 具身推理 LLM**(人格/对话/意图/规划;慢、语义)——**泛化"该干嘛"**(基础大模型白送语义/新颖情境泛化)。
- **小脑 = 连续动作 VLA**(**π0/π0.5/GR00T N1.7**,在你 rig 关节空间微调):感知→关节轨迹→RealityKit;快、运动——**泛化"怎么动"**(运动分布内)。
- **更快层**:行为基线 + 反射(<200ms,本地)在小脑之下。

**为何连续而非离散 token(open-vla 原首选取代)**:① 信息密度高、无量化,贴"高精度/活感";② 完美契前沿主线(GR2/π0-flow/GR00T 皆连续,下一代继承);③ "机器人形状"反对只在复用预训练输出时成立——**train-on-your-rig 消解**;④ 数据更顺(免 token 化)。**离散 token 降为 Phase1 fallback。**

**仍需微调(诚实)**:所有基础 VLA 对没见过的身体零样本都不行;但**模型(π0/GR00T)、感知、跨本体机制均现成**,只训"你 rig 关节空间"这段——行业标配、LoRA 单卡可起、比从零训轻。数据计划见 data-and-iteration(连续比离散更省)。

**据此修订**:open-vla 首选改连续;architecture-log 结论4(Brain=LLM+VLA)升级为"**大脑(具身推理 LLM)+ 小脑(连续 VLA)+ 行为/反射底层**"三层具身架构,泛化分工(大脑扛语义、小脑扛运动)。

### 13. 设计打磨方向(2026-08-03,用户输入;待细化,非锁定)
讨论中浮现 5 个方向,需打磨后再固化:

① **插件式预定义交互(game-like affordance)**:交互做成 `InteractionPlugin` 注册表(trigger=接近物体类/anchor、precond、actions、binding→小脑意图|fallback clip+affordance-fit、exit)。大脑从场景图 affordance + 接近事件发现可用交互→选择;小脑执行。把契约 B 的 affordance 标签从被动变可行动。先发小而精能力集(坐/躺/趴/看屏/靠近你/环顾)。**待打磨**:发现机制(push vs 查)、插件声明走小脑还是 clip。

② **3D 场景记忆可行性已验证**:VP 上已有付费 App 实现 mesh-only 持久记忆(无材质)→ 证明几何持久记忆可成、可上架。与本项目吻合(记忆=几何+语义,显示靠 passthrough,不需照片级重建)。该 App 缺语义层 = 我们的增值。**记为减风险,不改架构。**

③ **第一人称 POV 升级为主动作感知通道**(重构结论 8):当前"场景图为主、POV 仅凑近看"→ 改为**双视觉通道**——场景图(结构化)=记忆/信念层喂大脑;**角色第一人称 POV 渲染(图像)=实时视觉/核验层喂小脑 VLA + VLM**(VLA 本就吃图像,天然合流)。POV = 角色眼位置虚拟相机渲染真实 mesh+虚拟物。注意:角色 POV 是**合成渲染**(≠ 用户头显第一人称,两者视点不同)。强化结论 9"记忆=信念;实时=核验"。**待打磨**:连续渲染 vs 事件触发 vs 降分辨率(成本)。

④ **大脑架构已调研定稿**(2026-08,见 [`brain-agent-architecture.md`](brain-agent-architecture.md)):大脑 = **LangGraph StateGraph** 编排(单角色、checkpointer 持久)+ Graphiti/Milvus 记忆(上加 Letta/A-MEM 式"记忆自管工具")+ **ReAct(主线)/SayCan(选动作时乘场景图 affordance,兑现"记忆=信念、实时=核验")/ECoT 内心独白(活感)/Reflexion(失败教训)** + 系统提示词承载人格(不外采商用角色引擎)。**大脑→小脑条件化接口已收口**:契约 A Decision JSON → 意图编译器 → **NL 意图串 token-prefix** → π0/GR00T 原生 `prompt`(免适配器、免重训 backbone)。**小脑只扛身/大动作**;细通道(脸/眼/手/呼吸)走契约 A + MotionResolver。接地/"反诈" = SayCan 乘 affordance + 执行前核验 + LangGraph checkpoint 加密(⚠️ 2026-03 报两漏洞,上线须补丁)。〔原"最大开放项"已解,brain track 解除阻塞〕

⑤ **sim-first 研发拆分**(重构路线图):现实空间虚拟化→虚拟世界跑通交互→迁移。**关键 Apple 原生洞察:用 RealityKit 自己当 sim 环境**(Mac 虚拟房间),sim/AR 共用 rig/动画/交互/小脑 代码,只换两个插口(PerceptionSource、Display)。分阶段 A(纯 sim,不需 VP/entitlement)→B(真实感知接入)→C(AR 渲染出)→D(活感打磨/产品化)。详见 [`roadmap-phased.md`](roadmap-phased.md)。

### 14. VLA 演进策略:适配层 + 微调最小化 + 未来成熟 VLA 赌注(2026-08,用户决定)
**核心张力**:极 C(运动生成)**感知弱但运动细腻**;VLA **感知强但运动粗糙**——故多通道(极 C 扛意图驱动身体动作、VLA 扛感知驱动反应动作、契约 A 扛细通道)。一个未来"成熟 VLA"(感知+细腻运动统一)会把三者合一。
**适配层**:VLA 输出→归一化 SMPL-X→MotionResolver;换 VLA 只重写适配器(格式层便宜),但不解决行为分布(零微调=机器人式行为)。
**微调最小化三杠杆**:① 大量身体动作用运动生成(零 VLA 微调);② VLA 只留感知→动作闭环子集;③ LoRA action head(backbone 冻结)+ 数据存标准 SMPL-X(换 VLA=重 LoRA 不重采)。
**赌注(hedge)**:Phase 1/A **零微调**可跑(不依赖 VLA);等成熟 VLA 来了便宜插入。趋势(RT-X/UniAct/通用 humanoid 策略)同向。详见 open-vla 附 B。
